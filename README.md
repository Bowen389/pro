## 当前能力和限制

- 真实采集公开涨停池：代码、名称、收盘价、涨幅、首/末封时刻、开板次数、连续板数、封单比、换手率、来源标签。非全市场OHLC，非L2。
- 作者主页发现最新帖子，采集短公开片段：期末50分、橘子洲炒家实战、庄哥说股、延边刺客。身份标题校验，登录受限停在公开区，不恢复隐藏全文。网络失败保留状态。
- 同源历史快照对比、梯队统计、题材标签分组、逐股依据/反证、条件预案和后续池内出现核对。
- 前日和午间数据尚未积累时显示缺失。迟到、历史导入和真实盘前记录分开。
- 当前研究分只是透明、未校准的启发式，不等于龙头概率。没有完整分钟数据就不能证明带动性，没有队列数据就不能判断是否能排到板。
- 封单比不是封单留存率；一字与可成交性不由首封时刻单独判定。
- 模型接口已保留但不在定时任务中自动调用；本版没有声称完成AI语义研究、自动优化或盈利验证。后续需配置模型凭据并核验输出。
- 尚缺全市场指数/炸板/跌停池、历史日线/分钟、公司风险公告与除权口径、实时主动性验证、完整收益核算。

报告比简短摘要提供更多结构，但仍是数据驱动的研究稿，不能冒充已达到参考网站的完整数据深度。正式验收要求见[ACCEPTANCE.md](ACCEPTANCE.md)。

## 本地运行

Python 3.12，无第三方依赖。

```bash
python -m unittest discover -s tests -v
python src/pipeline.py --phase auto
```

state/external保存外盘与事件时间戳；state/close_observations保存盘内基础观察池；state/latest_by_phase.json及reports/LATEST.md分别指向各阶段最新报告。state/plans为不可覆盖的版本化预案；state/evaluations保留全部候选的后续核对（不在池不等于亏损、在池不等于成交）；state/sources记录公开材料可见性；state/snapshots保留源更新时间和观测时间。不要往公开仓库放任何密钥、个人持仓或券商日志。

数据源：https://www.jikefupan.com/ 。研究起点：https://olenara.com/longtou-qimo50-20261010.html 。数据和作者材料仅供研究，来源口径需持续核验。
